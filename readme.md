# ☕ Cafe Aziz Hotel & Restaurant

A **full‑stack MERN web application** for a modern hotel & restaurant management system. The project focuses on **real‑world booking, ordering, payment, and admin workflows**, built with scalability, performance, and clean architecture in mind.

🔗 **Live Website:** [https://bistro-boss-restaurant-kaptai.web.app](https://bistro-boss-restaurant-kaptai.web.app)

---

## 🚀 Project Overview

**Cafe Aziz Hotel & Restaurant** is a production‑ready platform where users can:

* Explore menu items
* Book tables / services
* Place food orders
* Complete secure online payments
* Manage bookings and orders through a dashboard

Admins can:

* Manage menu items
* Control bookings & orders
* Monitor payments
* Maintain overall system flow

This project reflects **real business logic**, not just UI demos.

---

## 🛠 Tech Stack

### 🔹 Frontend (Client)

* **React 18** (Vite)
* **React Router DOM v7**
* **TanStack React Query** (server‑state management)
* **Axios** (secure API communication)
* **Tailwind CSS + DaisyUI** (modern responsive UI)
* **React Hook Form** (form handling)
* **Firebase Authentication**
* **Stripe** (payment integration)
* **Recharts** (analytics & charts)

### 🔹 Backend (Server)

* **Node.js**
* **Express.js**
* **MongoDB** (native driver)
* **JWT Authentication**
* **Stripe API** (payment processing)
* **Nodemailer** (email notifications)
* **dotenv & CORS**

## ✨ Key Features

### 👤 Authentication & Security

* Firebase authentication
* JWT‑protected APIs
* Secure role‑based access (admin / user)

### 📅 Booking System

* Prevents past‑date bookings
* User‑specific booking history
* Server‑validated availability

### 🛒 Ordering & Payments

* Cart & checkout flow
* Stripe payment integration
* Payment history tracking

### 📊 Dashboard

* User dashboard (orders, bookings, payments)
* Admin dashboard (manage menu, orders, users)
* Real‑time data fetching with React Query

### ⚡ Performance & UX

* Optimized API calls with caching & staleTime
* Fully responsive design
* Clean UI with reusable components

## 🧠 Architecture Highlights

* Custom React hooks (`useAxiosSecure`, `useAuthValue`, `useMyBookings`)
* Centralized API handling
* Proper query invalidation & caching strategy
* Separation of concerns (UI, logic, data)
